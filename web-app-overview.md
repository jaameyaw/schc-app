# SCHC Website

Marketing site for Sylfi's Child Health Corner (SCHC), a Ghana NGO focused on child health.

## Organization

- Mission: empower families and caregivers on kids' health.
- Methods: education, advocacy, community outreach.

## App overview

- Public Next.js 16 site (React 19, Tailwind 4, Framer Motion).
- No backend in `package.json`, mostly static/marketing pages.

## Routes

| Page | Purpose |
| --- | --- |
| / | Hero, impact stats, program preview, about teaser, testimonials, CTA, newsletter |
| /about | Story, mission/vision, leadership |
| /programs | Program details (4 programs) |
| /volunteer | Volunteer and partner pitch |
| /donate | Donation and program tie-in |
| /contact | Contact |
| /gallery | Photo gallery by program/category |

## Programs

- Stitch-A-Uniform
- Feed and Treat the Street
- Monthly Miracle Fund
- Healthy Bridge Initiative

## Stack extras

- Phosphor/Lucide icons
- `sharp` plus optimize-images script
- Puppeteer (likely screenshots/PDF, not core user flow)

Branded nonprofit web presence for SCHC Ghana to inform, show impact, and drive volunteer, donate, and contact actions.
